# 🌸 Hadiah Special untuk Suci

1. Taruh file lagu **Die With A Smile** di `music/` dengan nama persis: `die-with-a-smile.mp3`
2. Upload semua isi folder ini ke repo GitHub
3. Repo → Settings → Pages → Branch `main` / root → Save
4. Link: `https://USERNAME.github.io/NAMA-REPO/`

Ganti nama / teks: `index.html` (bagian `.message`) dan `script.js` (bagian `CONFIG`).
Kalau mp3 belum ada, otomatis diputar musik lembut cadangan.
